I'm an ICT undergraduate at the Singapore University of Social Sciences (SUSS), specialising in cybersecurity. CLI-Only by Design

Password Analyzer

A Python terminal tool that analyses password strength, entropy, complexity, and breach exposure. Integrates the Have I Been Pwned API using k-anonymity for privacy-preserving breach checks. Implements a 0–100 risk scoring system with colour-coded output and improvement suggestions.

Deliberately built as a local CLI tool — no web app — to eliminate password transmission over the network. A conscious threat modelling decision.
